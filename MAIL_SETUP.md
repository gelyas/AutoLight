# Настройка отправки заявок в Telegram

## 1) Подготовить переменные окружения

Скопируйте `.env.example` в `.env` и заполните:

- `TELEGRAM_BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather)
- `TELEGRAM_CHAT_ID` — id чата, куда приходят заявки (личный чат, группа или канал)

Перед первым тестом напишите боту `/start` в Telegram.

## 2) Запуск

```bash
npm install
npm start
```

По умолчанию сервер стартует на `http://localhost:8080`.

Для PowerShell:

```powershell
$env:PORT=8081; npm start
```

## 3) Как это работает

- Фронт отправляет форму на `POST /api/lead`
- Backend валидирует поля и антиспам-правила
- Backend отправляет сообщение в Telegram через Bot API

## 4) Проверка

1. Откройте сайт.
2. Заполните форму «Обсудим ваш проект».
3. Нажмите «Отправить заявку».
4. Проверьте сообщение в Telegram.
